# Проектирование информационных ресурсов

МДК 01.01, специальность 09.02.09 «Веб-разработчик». Четыре лекции с планом по 120 минут. Сквозной учебный пример — сервис «Проектный навигатор».

В каждой лекции 65 слайдов: титул, цель и результаты, план, основная и дополнительная литература, восемь предметных вопросов, итоги, материалы и заключительный разбор. Сохранены ID всех исходных 240 слайдов; новые вводные и итоговые слайды имеют отдельные ID. Тесты, опросы и ожидание ответов аудитории не добавлены.

## Проведение занятия

Откройте лекцию и заполните профиль преподавателя через меню с тремя точками. ФИО, должность и кафедра сохраняются в текущем браузере. В этом же меню доступны тема, сценарий, источники и скачивание. Содержание открывается отдельной кнопкой; стрелки и PageUp/PageDown листают слайды, Home/End ведут к первому и последнему.

«Режим показа» открывает панель преподавателя. Кнопка «Открыть окно аудитории» создаёт отдельное окно со слайдом. Тема, слайд, указка и шаг открытой схемы синхронизируются. Сценарий и управление остаются у преподавателя. «Завершить показ» убирает слайд из окна аудитории до следующего явного запуска.

На предметных слайдах кнопка «Развернуть схему» открывает пошаговый разбор. Всего подготовлено 15 схем с 25 сценариями: состояния заявки, архитектура, путь пользователя, ключи и кратности, JOIN, атомарное решение, конкуренция, транзакция и закрытие проекта, путь запроса, границы длины, потерянный ответ, конверсия, уведомление и базовый поиск. Схемы начинаются с обзора. Структурные модели разбираются вручную; последовательности имеют «Показать / Пауза / Повторить». Смена условий возвращает к исходному состоянию.

Основная литература: Муромцевы и Мейер. Дополнительная: Крынецкая и Алексахин с соавторами. У каждой книги — отдельная карточка, QR-код и ссылка «Открыть источник». [Материалы курса](https://disk.yandex.ru/d/P40mjNJWYJAW9g) доступны из каталога и на отдельном слайде с QR-кодом.

## Скачивание

В каталоге доступны сценарии Markdown и PDF. Автономный HTML скачивается из меню лекции; изображения, шрифт, литература и интерактивные схемы встроены в файл. Для открытия внешней книги или папки материалов требуется интернет и, при необходимости, доступ к библиотеке.

PDF содержит слайды 16:9 и расположенные сразу после соответствующего объяснения статичные разборы всех сценариев. Поэтому число страниц PDF больше числа экранных слайдов. Начальный кадр плеера не подменяет полный результат схемы. Готовые PDF используют нейтральную подпись «Преподаватель»; для своих данных воспользуйтесь печатью из браузера.

Связные тексты для подготовки преподавателя находятся в `materials/webinar-N-teacher.md`, сценарии показа — в `materials/webinar-N-script.md`. Карты `webinar-N-alignment.json` связывают каждый ID, видимый номер и заголовок с обоими текстами и SHA-256 точного `course.json`. Это контракт данного приложения; импорт в другой движок не заявляется.

## Разработка и проверка

Нужен Node.js 22 или новее. Обычная генерация и сборка не требуют установки пакетов.

```sh
npm run dev
npm run build
```

По умолчанию локальный сервер использует порт 4176; переменная `PORT` позволяет выбрать другой. `npm run generate` пересоздаёт JSON, оба вида преподавательских текстов, карты и четыре автономных HTML. Готовая статическая сборка находится в `dist/`.

Для браузерной проверки и экспорта нужен доступный Playwright с Chromium, Chrome или Edge. Если Playwright установлен вне проекта, задайте `PLAYWRIGHT_MODULE_PATH` — полный путь к его `package.json`. `SITE_URL` задаёт адрес уже запущенного локального сервера.

```sh
node scripts/review.mjs
node scripts/export-pdf.mjs
npm run check
```

Для проверки декодирования QR дополнительно задайте `JSQR_PATH` — путь к браузерному `jsQR.js`. Для перегенерации SVG используется `node scripts/qr.mjs` с доступным модулем `qrcode`; при внешнем расположении задайте `QRCODE_MODULE_PATH` — путь к его `package.json`. Готовые SVG входят в репозиторий, генератор QR не требуется для обычной сборки.

Расчёт речи при 110 словах в минуту с предусмотренными паузами составляет около 114–118 минут. План 120 минут перераспределён по фактическому объёму речи после добавления структуры; это расчёт, а не проведённый хронометраж. Перед занятием нужен прогон под темп преподавателя.

Содержательная карта и границы проверки — в `docs/REVIEW.md`. Учебные запросы, показатели и сценарии не являются результатами испытания работающего сервиса или базы данных.

GitHub Actions собирает ветку `main` и публикует сайт через GitHub Pages.
