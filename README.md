# Проектирование информационных ресурсов

Учебный курс для специальности 09.02.09 «Веб-разработчик». Четыре лекционных вебинара по 60 слайдов с планом 120 минут на каждый. Единый пример — сервис «Проектный навигатор».

В каждом вебинаре есть титульный слайд, маршрут, восемь вопросов, подготовленные разборы и заключительные вопросы с готовыми ответами. Каждый слайд сопровождается полной речью, подсказками ведущему, описанием изображения и временем. Задания аудитории и ожидание ответов в сценарий не входят.

## Проведение занятия

1. Откройте сайт и заполните «Настройку перед занятием». Данные преподавателя сохраняются в текущем браузере.
2. Нажмите «Открыть вебинар». Для выбора слайда нажмите счётчик или кнопку содержания. Стрелки клавиатуры, PageUp/PageDown, Home/End также управляют показом.
3. В «Инструментах» включите сценарий. При необходимости откройте отдельное окно аудитории и перенесите его на экран трансляции. Оно показывает только слайды и следует за ведущим.

На каждой карточке доступны сценарий в Markdown и готовый PDF. HTML для просмотра без интернета можно скачать через меню загрузки внутри вебинара. В HTML встроены изображения, шрифт, все слайды и сценарий. На другом компьютере достаточно открыть скачанный файл в браузере.

Готовые PDF содержат нейтральную подпись «Преподаватель». Чтобы сохранить PDF со своими данными, откройте «Настройку перед занятием», выберите вебинар и используйте печать браузера. При печати включите фон и отключите системные колонтитулы. Слайды печатаются на отдельных страницах A4 в альбомной ориентации.

План рассчитан на 120 минут. Объём речи при 110 словах в минуту с указанными паузами даёт около 117–120 минут на занятие. Перед проведением следует сделать пробное чтение под собственный темп. Учебные макеты, проверки и показатели не являются реализацией сервиса или результатами реальных измерений.

## Файлы и сборка

- `authoring/` — исходный промпт и редактируемое содержание.
- `course.json` — сформированные слайды и сценарии.
- `materials/` — четыре HTML, четыре сценария и четыре PDF.
- `docs/SOURCES.md` — происхождение оформления и первичные технические источники.

Нужен Node.js 22 или новее. Веб-приложение и обычная сборка не требуют установки пакетов.

```sh
npm run dev
npm run build
```

Сайт доступен по адресу `http://127.0.0.1:4176/`. Сборка находится в `dist/`. При изменении содержания команда `npm run generate` пересоздаёт JSON, сценарии и HTML. Для обновления PDF на запущенном сайте выполните `node scripts/export-pdf.mjs`, затем сборку. Экспорт и проверка браузера используют Playwright из установленного пакета либо встроенной среды Codex; при отдельной установке нужны пакет `playwright` и браузер Chromium или Edge.

`npm run check` проверяет структуру, комплектность сценариев, время и автономные HTML. `node scripts/audit.mjs` проверяет все 240 слайдов в браузере, скачивания, профиль, поиск, режим ведущего, синхронизацию, мобильную ширину и автономные файлы. Служебные снимки сохраняются в игнорируемой папке `output/`.

GitHub Actions собирает сайт из ветки `main` и публикует его через GitHub Pages.
