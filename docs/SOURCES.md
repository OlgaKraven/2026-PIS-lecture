# Источники и оформление

Содержание основано на пользовательском промпте, сохранённом в `authoring/brief-original.txt`. Точное название дисциплины и специальность взяты из задания. Схемы, таблицы, макеты, примеры запросов и речь созданы для «Проектного навигатора».

## Оформление

[2026-PISID3-lecture](https://github.com/OlgaKraven/2026-PISID3-lecture) использован как визуальный образец: Raleway, фирменный знак, палитра, обрамление слайда, носорог, орнамент, стрелка разделителя и расположение управления. Учебные инфографики и содержание исходного курса не перенесены. Носорог и графические элементы оформления сохранены по прямым замечаниям пользователя. Уведомление о лицензии исходного проекта находится в `assets/DESIGN-LICENSE.txt`. Знаки и брендовые материалы сохраняют права их владельцев.

## Доработка МДК 01.01

Оформление приведено к утверждённому эталону презентаций от 22.10.2026: светлая и тёмная поверхности слайдов, полный логотип на титуле, знак на внутренних слайдах, серая стрелка вопроса влево, номера вопросов, меню из трёх точек и разделение окон. Тематический носорог `rhino-designer.webp` сохранён из исходного проекта и используется только в каталоге и титуле. Полный логотип взят из сохранённого эталона; обязательные лицензии исходных ресурсов сохранены.

Литература выбрана из списка пользователя. Основная: В. В. Муромцев и А. В. Муромцева, «Информационные технологии в профессиональной деятельности» (2023); Б. Мейер, «Основы объектно-ориентированного проектирования» (2024, издание для СПО). Дополнительная: Г. С. Крынецкая, «Вычислительные машины, сети и системы» (2023); А. Н. Алексахин, И. Ю. Владыко, Е. В. Сибирская, «Программное обеспечение управления проектами» (2025). Библиографические данные и адреса сохранены по пользовательскому списку. Карточки Муромцевых и Алексахина сверены с доступными описаниями IPR SMART; полные тексты книг не использовались. Для карточек Мейера и Крынецкой автоматическое чтение сайта ограничено; точные главы и страницы не назначались.

Для уточнения интерактивов использованы [ограничения PostgreSQL](https://www.postgresql.org/docs/current/ddl-constraints.html), [блокировки](https://www.postgresql.org/docs/current/explicit-locking.html), [соединение и фильтрация таблиц](https://www.postgresql.org/docs/current/queries-table-expressions.html), [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html). Дополнительные строки 105 и 106, проект 18 и студент 99 в JOIN — отдельный явно обозначенный учебный набор; основной пример заявки 104 и проекта 17 сохранён.

Модель закрытия проекта предполагает, что обе операции блокируют одну строку проекта в транзакции. Без этой общей дисциплины показанный порядок не гарантируется. Поиск по тегам — прозрачный базовый пример для сравнения с предполагаемым смысловым поиском; он не выдаётся за реализацию модели ИИ. Таймаут доставки не означает отсутствие доставки; повтор может дать дубликат уведомления, если канал не поддерживает дедупликацию.

[Папка материалов](https://disk.yandex.ru/d/P40mjNJWYJAW9g) предоставлена пользователем; её закрытое содержимое не использовалось для вывода о покрытии программы.
